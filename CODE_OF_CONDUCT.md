# Code of conduct

This project is a public workshop, not a support desk. Be direct, be specific, and leave other people's private lives out of it.

- Critique the code or the behaviour, not the person.
- Do not post tenant data, property addresses, account numbers, or identity documents.
- Do not harass, threaten, or pile on.
- Follow the licence. Do not ask the maintainers to add someone else's private records to the sample data.

Maintainers may edit, hide, or lock comments and issues that break these points. Repeated abuse can mean a block from the repository.

Questions about this file can go to [support@nexerav.com](mailto:support@nexerav.com).
